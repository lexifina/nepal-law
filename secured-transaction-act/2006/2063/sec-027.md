# Sec. 27. Continuity of maturity
(1) A security interest shall be deemed to be matured continuously if it is first matured in one manner and later matured in another manner in a manner that the continuity of the security interest is not interrupted.
(2) If a security holder assigns a matured security interest, it shall not be required to file a notice under this Act to give continuity to the maturity of the security interest against creditors of the security giver, transferees from the security giver, and lien holders.
